# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Security is central to the JARVIS Agentic Workflow Fabric (AWF). All mutating actions, external tool invocations, and host interactions run through deterministic sandbox and capability guard boundaries.

If you discover a security vulnerability:
1. **Do not** file a public issue.
2. Report the vulnerability privately to the project maintainers.
3. Provide a clear reproduction script, affected components, and potential impact.

Maintainers will acknowledge receipt within 48 hours and work with you on coordinated disclosure.
